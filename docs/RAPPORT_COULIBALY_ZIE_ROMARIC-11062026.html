Bilan des travaux réalisés le 11 juin 2026 sur UpJunoo Pro (Next.js 15, API v1 live).

Focus du jour : parcours d'inscription assisté par IA (wizard 4 étapes), double provider OCR (openrouter vision · paddle VPS), OTP création chauffeur, pages dédiées règles de commission, améliorations UX mobile et formulaire chauffeur (indicatif téléphone dynamique).

Regroupement des images (wizard)
  • Par type de document — une requête HTTP par CNI, permis ou carte grise (recto+verso groupés).
  • Mode Paddle — OCR VPS image par image, puis fusion texte → un appel OpenRouter texte.
