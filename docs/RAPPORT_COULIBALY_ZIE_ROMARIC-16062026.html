Points forts identifiés

  • Réseau complet : franchises, zones, partenaires, comptables
  • Flotte : chauffeurs, véhicules, KYC, clients
  • Finance admin riche + portail compta structuré (journal, périodes, réconciliation)
  • Support tickets + chat ; paramétrage tarifs, commissions, bonus, audit
  • Compta : retraits en lecture seule, philosophie « sans exécution des paiements »
