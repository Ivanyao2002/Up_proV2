Intégrations réalisées

Détail technique des branchements effectifs sur l'environnement api.upjunoo-dev.tech (documenté dans docs/API-INTEGRATION-BACKOFFICE.md).

Infrastructure & configuration
  • Client HTTP unifié avec routage /v1/ vs /api/v2/ (legacy mocks MSW).
  • Variables d'environnement : NEXT_PUBLIC_API_URL, NEXT_PUBLIC_USE_REAL_AUTH, NEXT_PUBLIC_MAPBOX_ACCESS_TOKEN.
  • Headers portail : Authorization, X-Client-Type: back-office, X-Scope, franchise / owner.
  • Guards d'authentification (AuthGuard, GuestGuard) et hydratation session.

Carte live — stack temps réel & rendu
  • Socket.io : événement admin:live:locations, statuts connecté / déconnecté, badge UI « Temps réel actif ».
  • Fusion données : snapshot HTTP une fois au chargement ; deltas GPS fusionnés sans re-polling agressif (30 s en secours si socket coupé).
  • Mapbox GL : marqueurs chauffeurs, popups enrichies, icône GPS personnalisée.
  • Animation : itinéraires Mapbox Directions (throttle), vitesse speed_kmh, extrapolation entre paquets socket — mouvement fluide sur voies.
  • Documentation technique : ADMIN-LIVE-MAP-SOCKET.md.
Qualité & outillage
  • Typage TypeScript (mappers API → modèles UI), React Query pour cache et mutations.
  • Mode mocks MSW conservé pour développement hors-ligne et écrans non encore branchés.
  • Compilation tsc --noEmit validée sur le socle intégré.
