VH — Création véhicule + chauffeur

Flux technique testé live et correction du bug chauffeur.

Flux admin (testé live)
1. POST /v1/vehicles
   Body: partnerId, categoryCode, brandCode, modelCode, colorCode,
         manufactureYear, seatsCount, plateNumber
   → 201, vehicle.id

2. (si chauffeur coché)
   POST /v1/auth/driver/register  → token chauffeur
   POST /v1/drivers/onboarding/start (JWT chauffeur) → driver.id
   POST /v1/partners/{partnerId}/members { userId, role: "DRIVER" }
   POST /v1/vehicles/{id}/assign-driver { driverId }
   → 200
Problème résolu : le front appelait POST /api/v2/partner/drivers (404). L'erreur était avalée silencieusement → véhicule créé sans driver_id. Après correction : flux v1 ci-dessus ; erreurs chauffeur remontent à l'UI.
