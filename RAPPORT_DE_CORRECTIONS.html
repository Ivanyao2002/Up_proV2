Interface Franchise - UPJUNOO PRO

Bouton Suspendre non fonctionnel

MOYENNE Interface Franchise - Liste des clients

CONSTAT

Le bouton "suspendre" ne fonctionne pas dans la liste des clients. Aucune action n'est déclenchée lors du clic sur ce bouton.

ÉTAPES POUR REPRODUIRE

  • Aller dans l'onglet client
  • Repérer un client dans la liste
  • Cliquer sur le bouton "suspendre"
  • Observer l'absence de réaction

COMPORTEMENT ATTENDU

Une notification confirmant que le client est suspendu et un changement de statut visible dans l'interface.

CORRECTION PROPOSÉE

Le backend doit créer une route pour gérer la suspension des clients et le front doit implémenter l'appel à cette API avec mise à jour de l'interface.
